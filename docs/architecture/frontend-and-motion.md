# Frontend and motion

## Pages

| Route | Contents |
| --- | --- |
| `/` | Search a Stock Token, the list of tracked tokens, and the legend explaining each overall status. |
| `/assets/{TICKER}` | Overall status, then token, transfer, trading, oracle, underlying and corporate-action status — each with its source, verification state and observation time. |
| `/assets/{TICKER}` (untracked) | `not-found.tsx`. |

Both pages read through `lib/provider.ts`, the same module the API uses.

| Component | Role |
| --- | --- |
| `Search` | Ticker lookup on the home page. |
| `StatusGrid` | The tracked-token table; hover is a transform-only compositor animation. |

## Design tokens

`app/globals.css` defines the palette as CSS custom properties, re-exported to Tailwind 4 through `@theme inline`. The language is charcoal-on-paper with a serif display face, hairline rules and tracked-caps buttons — ivory `--paper`/`--cream` grounds, `--ink` type, and status colours `--green` (active), `--warn` (warning), `--orange` (blocked), `--sage` (verified).

Editing a colour means editing the token, not the component.

## The motion layer

Two client components wrap the app.

**`SmoothScroll`** runs Lenis (`lerp: 0.09`, anchor offset `-88` to clear the fixed header) driven by GSAP's ticker, so ScrollTrigger and every scrubbed tween read the same eased scroll position on the same frame. That shared clock is what makes the ticker lean, the parallax and the footer botanicals glide rather than step.

**`MotionRoot`** holds one GSAP context for the whole page, rebuilt on every route change, and registers `ScrollTrigger` and `SplitText`. Animations are declared in markup by data attribute:

| Attribute | Effect |
| --- | --- |
| `data-hero` / `data-hero-item` / `data-hero-art` | One orchestrated page-load sequence. |
| `data-split` | Headings rise line by line out of a mask. |
| `data-reveal` | Scroll-in entrance, batched so neighbours stagger. |
| `data-stagger` | Children enter one after another. |
| `data-parallax="0.6"` | Scrubbed drift against the scroll. |
| `data-scrub-rotate="3"` | Scrubbed tilt as the section scrolls away. |
| `data-drift` | Illustration slides a little inside its tile. |
| `data-marquee` | Ticker that speeds up and leans with the scroll. |
| `data-count` | Numbers roll up from zero when they enter. |

`EcoRow` and `Parallax` add GSAP `quickTo`-driven hover and scroll effects at the component level; `Petals` and `Reveal` cover the decorative and entrance cases.

{% hint style="info" %}
Under `prefers-reduced-motion: reduce`, Lenis is skipped entirely and every animated element is simply shown in place. Content never depends on motion to become visible.
{% endhint %}
